# SAMI UZZAMAN Maintenance Portfolio

This is a static website prepared for GitHub Pages publishing.

## Files

- `index.html` - main website page
- `style.css` - site styling

## Quick customization

Update these placeholders in `index.html` before publishing:

- phone number
- email address
- WhatsApp number
- project photos
- video embed or YouTube link

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `style.css` from this folder.
3. In the repository settings, open `Pages`.
4. Set the source to `Deploy from a branch`.
5. Choose the `main` branch and `/root`.
6. Save and wait for the site URL.
